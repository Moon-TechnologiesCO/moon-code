Instalar

Elige la opción que te quede mejor. El paquete trae todas sus dependencias.

Ubuntu / Debian (.deb)

Descarga el paquete desde las releases y ábrelo, o instálalo desde la terminal:

sudo apt install ./moon-code_0.1.0_amd64.deb

Después búscalo en el menú de aplicaciones como Moon Code.

Con pip

Si ya usas Python 3.11 o superior:

pip install "git+https://github.com/Moon-TechnologiesCO/moon-code.git"
moon ./mi-proyecto
