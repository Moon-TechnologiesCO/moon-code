Features

A complete editor. No window required.

Moon Code feels familiar from the first keystroke: the layout, the shortcuts and the workflow you already know.

🗂️

Explorer & tabs

Material-style colored icons, right-click menu to create, rename or delete (to the Trash), Git colors and Quick Open (ctrl+p).

💡

Real IntelliSense

Methods as you type, signature help, hover docs, go to definition (F12) and errors underlined in a Problems panel. Python built in; other languages use the same servers as VS Code.

⌨️

Integrated terminal

A real shell inside the editor (ctrl+j). Run git, npm, docker or anything else without leaving.

▶

One-key run

F5 runs the active file, ctrl+F5 the project. Compiled languages are built and run for you.

🤖

Local AI

Chat with models running on your machine through Ollama. Ask about the active file — your code never leaves your computer.

🧩

Extensions

Turn features on and off in one click, or write your own extension in a single Python file.

🔍

Search & Git

Search across the whole project, see changed files and your branch, and edit with auto-indent, bracket pairs, find & replace and comments.

🌙

Beautiful by default

A macOS-inspired interface with Moon Night, Moon Midnight and Moon Light themes. Starts in a blink.

Install

Choose how you want to install

The automatic installer does everything for you. Prefer to do it by hand? Every manual option is here too.

1

Run one command

Open a terminal and paste this. It detects your system: on Ubuntu/Debian it installs the .deb with apt, on macOS it installs Moon Code and creates the app.

curl -fsSL https://moon-technologiesco.github.io/moon-code/install | bash
2

Open it

Find Moon Code in your apps menu (Launchpad on macOS), or run it from any folder:

moon .
3

Stay up to date

Moon Code tells you when a new version is out. Update with:

moon update
1

Download the package

The package includes all its dependencies. You only need Python 3.10 or newer, which Ubuntu and Debian already include.

Download .deb from Releases
2

Install it

Double-click the file, or install it from the terminal in the folder where you downloaded it:

sudo apt install ./moon-code_0.3.0_amd64.deb
3

Open it

Search for Moon Code in your applications menu. It opens in a terminal, ready to code.

1

Make sure you have Python 3.10+

Check with python3 --version. If it's missing, install it with Homebrew or the Xcode command line tools:

brew install python
2

Run the installer

It installs Moon Code in ~/.moon-code, adds the moon command and creates Moon Code.app in ~/Applications.

curl -fsSL https://moon-technologiesco.github.io/moon-code/install | bash
3

Open it

Launch Moon Code from Launchpad or Spotlight. It opens in Terminal. Shortcuts use ctrl, like on Linux, so they work in every terminal.

1

Install with pip

If you already use Python 3.10 or newer (ideally inside a virtual environment):

pip install "git+https://github.com/Moon-TechnologiesCO/moon-code.git"
2

Open a project

moon ./my-project
3

Uninstall any time

curl -fsSL https://moon-technologiesco.github.io/moon-code/install | bash -s -- --uninstall

Extensions

Make it yours in one file

Built-in extensions (Code Runner, Formatter, Git, Moon AI, Autocomplete) toggle with one click. Your own extensions are a single Python file — create one from the Extensions view.

# ~/.config/moon-code/extensions/hello.py
NAME = "Hello"
DESCRIPTION = "Greets the active file"

def activate(api):
    def hello():
        path = api.active_file()
        api.notify(f"Hello, {path.name}!")

    api.add_command("Hello: Greet", "Say hi", hello)
    api.add_command("Hello: Run tests", "pytest",
                    lambda: api.run_in_terminal("pytest -q"))
FAQ

Questions

Is Moon Code free?

Yes. It's open source under the MIT license, made by Moon Technologies.

Does the AI send my code to the cloud?

No. Moon AI only talks to Ollama on your own machine (localhost). Install Ollama and pull a model, for example: ollama pull gemma3n:e2b.

Which terminals does it work in?

Any modern terminal: GNOME Terminal, Ptyxis, Konsole, Kitty, Alacritty, WezTerm, iTerm2 and macOS Terminal. Mouse and colors are supported.

Do I need Neovim or another editor?

No. Moon Code is its own editor and the package installs everything it needs.

Which languages have IntelliSense?

Python works out of the box. JavaScript, TypeScript, Go, Rust, C/C++, C#, HTML, CSS, JSON, Lua, Bash, PHP and more use the same language servers as VS Code: open a file and Moon Code tells you how to install its server (F1 → IntelliSense: Install Language Server).

How do I update?

Run moon update. Moon Code checks for new versions on start and shows a notice in the status bar.
